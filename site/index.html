Plot numbers from stdin.

PipePlot is a macOS utility for following numbers over time. Pipe numeric output into pp, or have it run a command repeatedly.

Zoom, select a time range, and read off values while capture continues. Sessions are saved locally.

Usage reference

Examples

macOS · zsh / bash

These commands assume pp is installed and on your PATH. Each opens a new chart (-c). Stop a running example with Ctrl-C; captured data remains saved.

Track a process’s memory

Sample resident memory once a second, in KiB. This runs as written for your current shell; replace $$ with another process ID to track that process.

shell
pp --watch "ps -p $$ -o rss=" --interval 1 \
  -c -n rss -u KiB

RSS is resident memory, not the “Memory” figure in Activity Monitor. Sampling stops if the process exits.

Track system load

Read the one-minute load average once a second. Uses the macOS sysctl command.

shell
pp --watch 'sysctl -n vm.loadavg | awk "{print \$2}"' \
  --interval 1 -c -n load

Adapted from the load-average example in ttyplot.

Plot ping times

Plot 30 round-trip times in milliseconds. This example uses loopback; replace 127.0.0.1 with your router or another host.

shell
LC_ALL=C ping -c 30 127.0.0.1 |
  sed -n -l 's/.*time=\([0-9.]*\) ms.*/\1/p' |
  pp -c -n latency -u ms

Adapted from ttyplot and wesplot. On macOS, sed -l flushes each line. Headers and unanswered pings produce no samples.

Plot a transfer rate with pv

Send 20 MiB of zeroes to /dev/null, limited to 2 MiB/s, and plot bytes per second. Requires pv (brew install pv). No file is created.

shell
{ dd if=/dev/zero bs=1048576 count=20 2>/dev/null |
    pv -n -r -L 2m -i 0.5 >/dev/null
} 2>&1 | pp -c -n throughput -u B/s

pv’s numeric rate output goes to stderr. The group sends that output to pp and discards the transferred bytes. This is a rate-limited demonstration, not a disk benchmark.

Try two generated signals

Generate two sine waves at one sample per second. No other command is needed.

shell
pp --test 2 -c

Each input column becomes a separate line. All columns are values; timestamps are assigned when rows arrive.

Input

One row per sample, with spaces or tabs between numeric values. Each column becomes a line. Input is timestamped on receipt; a first column containing a timestamp is treated as another value.

Flush output from long-running producers so samples arrive promptly. With Python, use python3 -u or print(value, flush=True). Use pp --help for options, or see the usage guide for chart controls, selections and CSV export.

Install

Download PipePlot 0.2.0 preview for Apple Silicon and macOS 27 or later. Release notes and SHA-256 checksum.

Unnotarized preview: this build is ad-hoc signed, without Developer ID signing or Apple notarization. macOS may block its first launch. See Apple’s instructions if you choose to open it.

  1. Open the DMG and drag PipePlot.app to Applications.
  2. Open the installed app and choose PipePlot → Install pp Command….
  3. If Terminal cannot find pp, add the following to ~/.zprofile, then open a new Terminal window.
shell
export PATH="$HOME/.local/bin:$PATH"

Build from source

Requires Xcode with the macOS 27 SDK, just, POV-Ray, and Python 3 with Pillow.

shell
git clone https://github.com/alchemyst/pipe-plot.git
cd pipe-plot
just install

This installs ~/Applications/PipePlot.app and ~/.local/bin/pp. Add ~/.local/bin to your PATH if needed. See build instructions for details.

Related tools and inspiration

pv reports progress through a pipe. ttyplot plots stdin in a terminal. wesplot plots it in a browser. Their pipeline workflows and examples are inspiration for PipePlot, which uses a native macOS window and keeps a local capture history.

The examples above adapt those workflows to macOS and pp. See similar projects for more plotting tools.
